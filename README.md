# contman

## Backend

### Setup

```bash
cd backend
npm install
```

### Run

```bash
npm start
```

Server starts on `http://localhost:3000`.

### Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/users` | All users |
| GET | `/users/:id` | User by id |
| GET | `/companies` | All companies |
| GET | `/companies/:id` | Company by id |
